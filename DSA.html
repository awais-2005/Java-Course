How this ledger was built

Every entry is a real LeetCode problem — its official problem number was cross-checked against a canonical 2,900+ problem dataset before being included, so nothing here is invented. Company tags come from liquidslr/leetcode-company-wise-problems, a public archive of community-reported "which company asked this in an interview" data. A tag is only shown when that source actually recorded it.

The list is restricted to companies in that archive that are (a) payments, banking, or financial-data businesses, and (b) known for hiring heavily into Java / Spring Boot backend roles — so no design agencies, ad-tech, or gaming studios. Some names people naturally associate with fintech (Klarna, Adyen, Nubank, Binance, Plaid, Nasdaq) simply had no verified rows in the source archive, so they were left out rather than guessed at.

Problems were ranked by how many of these companies asked them and how frequently, then the strongest 1000 were kept and sorted Easy → Hard (by difficulty tier, then acceptance rate) into positions 1–1000.
